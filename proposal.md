# Hinojosa_Edward_FinalProject

## Repository
https://github.com/Hotdiggitydog200/Hinojosa_Edward_FinalProject

## Description
I will create a program in Python that allows the user to draw a picture. It will have basic features such as drawing, picking colors, etc

## Features
- drawing
	- The program should allow the user to use their mouse to draw lines on a canvas
- color picking
	- Be able to change the color of the drawing brush. 
- adjust/change brushes
	- Be able to adjust the size and spacing of your brush and even the shape.

## Challenges
- Need to learn how to receive input from a mouse and how to use it to draw pixels. 
- Need to learn to make buttons that can make change settings in my game loop.
- Need to learn how to change resolution.

## Outcomes
Ideal Outcome:
- The ideal outcome is creating a program where I can draw a picture using many different colors with a simple, useable ui and that can use custom brushes, with many features. 

Minimal Viable Outcome:
- can draw multiple colors, with an adjustable brush size and shape. 

## Milestones

- Week 1
  1. Create a canvas
  2. Create the ability to draw on this canvas

- Week 2
  1. Create a way to change the color of the brush as the program runs
  2. Create a way to change the size and shape of the brush. 

- Week N (Final)
  1. Add a way to change the resolution of the canvas
  2. Add any additional features such as layers or filters or just debug.
